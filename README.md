# 📊 Power Query & ETL Portfolio

Цей репозиторій містить практичні завдання та проєкти з очищення й трансформації даних за допомогою Power Query в Excel 365.

## 🛠️ Вивчені інструменти та навички
* **ETL-процеси**: Об'єднання запитів (`Merge`), трансформація таблиць (`Unpivot / Pivot`).
* **Робота з текстом**: `Split Column`, `Merge Columns`, `Conditional Column`.
* **Типи даних та дати**: Обробка помилок (`Replace Errors`), розрахунок термінів (`Subtract Days`).

## 📁 Структура проєктів
* `PQ_Lesson11_Practice.xlsx` — Текстові трансформації та умовні стовпчики.
* `PQ_Lesson12_Practice.xlsx` — Трансформація «широких» таблиць у «довгі» (`Unpivot`).
* `PQ_Lesson13_Practice.xlsx` — Робота з датами та очищення помилок.
